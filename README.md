# Functional-structural model for tomato
The model simulates 3D architectural development and growth of young tomato plants.

Paper: [https://doi.org/10.1093/insilicoplants/diaf022](https://doi.org/10.1093/insilicoplants/diaf022)

## Installation
Download GroIMP, recommended version 2.2.1: [https://download.grogra.de/](https://download.grogra.de/)

To run the model, open the project.gs file.
